## 🌟 Featured Projects

### 1. **3D Diwali Greeting Card** 🎇
An interactive animated greeting card with stunning 3D effects and dynamic animations.

**Features:**
- 3D animated diya (oil lamp) with flickering flames
- Dynamic fireworks with multiple burst patterns
- Sparkle and particle effects
- Responsive design for all devices
- Interactive click and hover effects
- Glowing shadow effects and gradient text animations

**Technologies:** HTML5, CSS3 (3D Transforms), Vanilla JavaScript
- [View Diwali Card](./index.html)
- [View on GitHub](https://github.com/Rohansom/diwali-card)

## 💻 Technologies & Skills

- **Frontend:** HTML5, CSS3 (Flexbox, Grid, 3D Transforms), JavaScript
- **Animations:** CSS Keyframes, Web Animations API, Transform3D
- **Design:** Responsive Design, Gradient Effects, Interactive UI
- **Web Development:** Modern web standards, Performance optimization
